# 📱 صندوق تحصيل الزكاة — الجمهورية اليمنية

نظام متكامل لإدارة وتحصيل الزكاة ومصروفاتها على الفئات الثماني، يعمل **دون إنترنت بالكامل** (Offline-First)، بهيكل ثلاثي المستويات:

> **المقر المركزي (صنعاء) ← فروع المحافظات (تعز، إب، الحديدة…) ← مراكز الزكاة**

---

## ✨ المزايا

| المجال | التفاصيل |
|---|---|
| 💰 **التحصيل** | تسجيل إيصالات زكاة المال، التجارة، الفطر، الأنعام، الزروع، سُبل الخير — بأرقام إيصالات تسلسلية تلقائية |
| 🤲 **الصرف** | المصروفات على الفئات الثماني المستحقة (الآية 60 من سورة التوبة) مع أسماء المستحقين |
| 📊 **التجميع التلقائي** | تُجمع بيانات المراكز تلقائياً إلى المحافظات فالمقر المركزي (Rollup) |
| 🖨️ **الطباعة الحرارية** | إيصالات 58مم/80مم عبر **البلوتوث (ESC/POS)** مع رمز QR — تُطبع كصورة نقطية لضمان العربية 100% |
| 📄 **الطباعة الرسمية A4** | نمط حكومي: شعار الصندوق، ترويسة رسمية، خاتم، تواقيع، ورأس وتذييل ثابت لكل تقرير — وكل تقرير له زر طباعة + PDF |
| 📈 **التقارير** | يومية/شهرية/سنوية، مقارنة المحافظات والمراكز، دفتر اليومية، الميزانية المبسطة، تقرير الفئات، مع رسوم بيانية |
| 📊 **Excel** | تصدير XLSX منسّق عبر SheetJS |
| 🔐 **الأمان** | صلاحيات ثلاثية (مدير عام/مدير فرع/موظف مركز)، سجل تدقيق كامل، تشفير AES-256 للنسخ الاحتياطية، تجزئة كلمات المرور SHA-256 |
| 💾 **النسخ الاحتياطي** | تصدير/استيراد JSON مع تشفير اختياري، وتُحفظ في مجلد التنزيلات على أندرويد |
| 🌐 **يعمل من ملف واحد** | انقر نقراً مزدوجاً على `index.html` — يعمل مباشرة من `file://` دون أي خادم |

---

## 🚀 التشغيل

### نسخة المتصفح (الأصلية)
1. حمّل المجلد كاملاً
2. انقر مزدوجاً على **`index.html`**
3. الدخول الافتراضي: **`admin` / `admin123`** (غيّرها فوراً من الإعدادات)

يعمل بأفضل صورة على Chrome / Edge / Samsung Internet. الطباعة الحرارية تحتاج متصفحاً يدعم Web Bluetooth (Chrome/Edge) وتفعيل بلوتوث الجهاز.

### نسخة الأندرويد
حمّل **`zakat-fund-v1.0.0.apk`** من صفحة [Releases](../../releases/latest) وثبّتها.

- ✔️ متوافق مع **Android 9 حتى Android 14** (API 28–34)
- ✔️ شاشة بداية أصلية بالشعار الذهبي الأخضر واسمي المطوّرين
- ✔️ الطباعة الحرارية عبر البلوتوث (قم بإقران الطابعة من إعدادات النظام أولاً)
- ✔️ الطباعة A4 و«حفظ كـ PDF» عبر مدير الطباعة الأصلي
- ✔️ النسخ الاحتياطي في مجلد Download عبر MediaStore/SAF

## 🏗️ البناء من المصدر (APK)

```bash
# نسخ تطبيق الويب إلى أصول أندرويد
rsync -a --exclude android --exclude .github --exclude .git ./ android/app/src/main/assets/

cd android
gradle assembleRelease     # الناتج: app/build/outputs/apk/release/app-release.apk
```

**CI جاهز:** يبني GitHub Actions ملف APK تلقائياً عند كل دفع إلى `main` وينشره في Releases.
المفتاح الذاتي التوقيع في `android/keystore/zakat-release.jks` (كلمة المرور: `zakat2025`) — استبدله بمفتاحك الخاص في الإنتاج.
